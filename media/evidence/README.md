# Selected evidence media

Only decision-critical public screenshots or photos belong here. Every file must have a matching record in `data/media.json` with the Reddit post URL, author, subreddit, attribution, capture date, SHA-256 hash, alt text, and research purpose. Large files are tracked by Git LFS.

Target-bag tile images are limited to user-posted images hosted on public Reddit posts. Official-brand imagery and images from seller catalogs, social media, or other websites are not used for these tiles. Candidate images stay out of the published tile set until they are locally archived and hashed.

If a contributor requests removal or correction, open the GitHub issue form for “Correction or Media Removal” with the public post URL and the affected family/media record.
