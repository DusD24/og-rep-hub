# Selected evidence media

Only decision-critical public photos belong here. Every file must have a matching record in `data/media.json` with its direct image URL, normalized Reddit evidence/post URL, author, subreddit, attribution, capture date, removal-check date, SHA-256 hash, pixel dimensions, meaningful alt text, and research purpose. Large files are tracked by Git LFS.

Target-bag tile images are limited to user-posted images from public Reddit posts. A Reddit author may expressly identify an externally hosted album as their personal photos; that album is permitted only when its URL is preserved alongside the Reddit post and evidence record. Official-brand imagery and images from seller catalogs, unrelated social media, or other websites are not used for tiles. Images enter the published tile set only after local archival, visual privacy review, hashing, dimension capture, and evidence linkage.

If a contributor requests removal or correction, open the GitHub issue form for “Correction or Media Removal” with the public post URL and the affected collection/media record.
