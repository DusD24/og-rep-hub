# Selected evidence media

Only decision-critical public screenshots or photos belong here. Every file must have a matching record in `data/media.json` with attribution, source URL, capture date, SHA-256 hash, and research purpose. Large files are tracked by Git LFS.

Target-bag tile images are limited to user-posted images hosted on public Reddit posts. Official-brand imagery and images from seller catalogs or other websites are not used for these tiles.
